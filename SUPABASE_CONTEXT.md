# Supabase & Database Architecture Context

## 1. Overview
The database backend runs on PostgreSQL via Supabase, protected by Row Level Security (RLS) policies. Authentication is handled using Supabase Auth with JWT access & refresh tokens.

## 3. Database Schema

### Table: `public.properties`
Stores real estate property listings.

| Column | Type | Constraints / Default | Description |
|---|---|---|---|
| `id` | `bigint` | `generated by default as identity primary key` | Unique property ID |
| `title` | `text` | `not null` | Listing title / headline |
| `city` | `text` | `not null` | City name (Karachi, Lahore, Islamabad) |
| `price` | `numeric` | `not null` | Price in PKR |
| `bedrooms` | `int` | `not null default 1` | Number of bedrooms |
| `bathrooms` | `int` | `not null default 1` | Number of bathrooms |
| `area` | `int` | `not null` | Area in square feet |
| `description`| `text` | `nullable` | Detailed description |
| `image_url` | `text` | `nullable` | Direct URL to property photo |
| `created_at` | `timestamptz` | `default timezone('utc'::text, now()) not null` | Creation timestamp |

### Table: `public.favourites`
Stores user-saved bookmarks.

| Column | Type | Constraints / Default | Description |
|---|---|---|---|
| `property_id` | `bigint` | `references public.properties(id) on delete cascade` | The favorited property ID |
| `user_id` | `uuid` | `references auth.users(id) on delete cascade default auth.uid()` | The authenticated user's ID |
| `created_at` | `timestamptz` | `default timezone('utc'::text, now()) not null` | Bookmark timestamp |

**Primary Key**: `(property_id, user_id)`

## 4. Row Level Security (RLS) Policies

```sql
alter table public.properties enable row level security;
alter table public.favourites enable row level security;

-- Properties: Public read access
create policy "Allow public read access on properties"
  on public.properties
  for select
  using (true);

-- Favourites: User isolation
create policy "Users can view own favourites"
  on public.favourites for select
  using (auth.uid() = user_id);

create policy "Users can insert own favourites"
  on public.favourites for insert
  with check (auth.uid() = user_id);

create policy "Users can delete own favourites"
  on public.favourites for delete
  using (auth.uid() = user_id);
```

## 5. API Layer Mapping

- [src/api/properties.ts](file:///c:/Users/Sony/Antigravity%20projects/OEL/src/api/properties.ts):
  - `fetchPropertiesPage(page, city)`: Queries `.range(from, to)` with optional city filter.
  - `fetchProperty(id)`: Queries single row by `.eq('id', id).maybeSingle()`.
- [src/api/favourites.ts](file:///c:/Users/Sony/Antigravity%20projects/OEL/src/api/favourites.ts):
  - `fetchFavourites()`: Queries `favourites` joined with `properties(*)`.
  - `addFavourite(propertyId)`: Inserts `{ property_id }`.
  - `removeFavourite(propertyId)`: Deletes where `property_id = propertyId`.
